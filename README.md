# 小D的采耳馆 · 手机版

鲸耳堂的采耳服务：**十一个小节、一分零九秒**，棉师傅（一只白猫）给我采耳、洗耳、烛耳、洗头、敷热毛巾。

- 手机打开：竖屏是封面，点「躺下开始」，然后**把手机横过来**看。
- 顶部两个按钮：声音开关、下一节。
- 播完会出一张「采耳报告」卡，可以保存成图片。
- 建议戴耳机，声音很轻。

## 怎么跑

纯静态站，不用构建：

```
python -m http.server 8000      # 或者任何静态服务器
# 然后打开 http://127.0.0.1:8000/
```

## 文件

```
index.html      开场 / 播放中按钮 / 采耳报告卡
app.js          手机外壳（横屏提示、按钮、报告卡画图、分享/保存）
earscene.js     画面本身（十一个小节的手绘动画 + 音频调度）
assets/earspa/  12 条音频
```
